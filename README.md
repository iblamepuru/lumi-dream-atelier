**LUMI** is an interactive storybook portfolio for a tiny moon moth who mends broken dreams and flies them home before sunrise. It is one character, one idea, and every page is a small machine for making you care about her.

---

## ✦ Try it in two minutes

No time to explore? The home page has a **Start Lumi's journey** checklist that walks the best path:

1. 🌟 **Wake the fallen star** Polara
2. 🔧 **Repair the dream crystal**
3. 🏮 **Build a lantern** and download its keepsake card
4. ✈️ **Deliver the dream** home across the Dream Delivery Navigator
5. 🔍 **Find a hidden star** (there are five, and they unlock a secret)

## 🌙 What's inside

| | |
| --- | --- |
| **📖 Origin story** `/story` | Four scroll-driven chapters with a travelling light: wake Polara, collect the fragments, inspect the observatory tools, begin the next journey. |
| **🛠️ Workshop No. 07** `/workshop` | Three connected inventions: **Dream Repair Lab** (mend a crystal), **Moonlight Lantern Studio** (design a lantern, download a keepsake card), **Dream Delivery Navigator** (fly the dream home, synced to scroll). |
| **🎲 Night Playroom** `/playroom` | A star-comb **music box** with an original lullaby you can record and replay, plus *Catch the Falling Dreams*, where every catch plays the next note. |
| **🧸 Dream Friend Maker** `/dream-friends` | Sew your own ghost, cloud, robot, alien, monster or fantastical you, then keep it on the nursery shelf. |
| **✍️ Sleepers' Guestbook** `/guestbook` | A live, shared wish wall with a mechanical visitor odometer. |
| **💬 Ask Lumi** | Chat with Lumi in character (Claude), with storybook replies as a graceful fallback. The UI says plainly which one you're getting. |
| **🌌 Constellation hunt** | Five hidden stars unlock a constellation, a diary page and a golden crown. |
| **🕹️ 90s Chaos Mode** | A responsive early-web alternate layout, with webring and classic badges. |

### Reacts to you

- Eyes follow your cursor (with a touch fallback), clicks change Lumi's mood, and she **dozes off after 20 seconds of stillness**. Wake her up.
- A **Twilight / Midnight** toggle changes the palette *and* her expression.
- Sound starts **muted**; the mute switch is visible on every screen and remembers your choice.
- Lumi remembers returning visitors.

## 🛡️ Built to be shared safely

- **Guestbook:** rate limits stored in Netlify Blobs (3 wishes per visitor per 10 minutes, 60 a day site-wide), a hidden honeypot and minimum fill-in time against bots, and gentle moderation that turns away links, emails, phone numbers and rude words with a friendly message. The odometer counts each visitor at most once a day. Visitor IPs are only ever stored as **salted hashes**.
- **Ask Lumi:** per-visitor limits (15 replies per 10 minutes) and a site-wide daily cap (`LUMI_DAILY_CHAT_CAP`, default 400) protect the API budget. If AI is unavailable, Lumi answers from the storybook instead.

## 🧰 Tech

React 19 · TypeScript · Vite · Tailwind CSS · Three.js · Web Audio API · HTML5 Canvas · Netlify Functions + Netlify Blobs · Anthropic SDK (Claude)

A static boot screen with inlined CSS paints before the app loads; below-the-fold sections and Three.js load on demand; idle animation loops pause. Reduced-motion is respected.

```
src/
  components/   hero, character sheet, story, workshop, guestbook, chat, chaos mode, webring…
  projects/     Dream Repair Lab, Lantern Studio, Delivery Navigator
  playroom/     Lullaby Lab, Catch the Falling Dreams
  friends/      Dream Friend Maker
  context/      shared state + localStorage memory
  router.ts     tiny History-API router (no dependencies)
netlify/functions/
  guestbook.mts   /api/guestbook  (wishes + visit counter in Netlify Blobs)
  lumi-chat.mts   /api/lumi-chat  (Claude, in character, rate limited)
scripts/
  capture-screenshots.mjs   regenerates every screenshot in this README
```

### Run it locally

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # type-check + production build
npm run lint
npm test             # Playwright end-to-end tests (desktop + phone)
npm run lighthouse   # mobile Lighthouse audit → docs/lighthouse/
```

Locally the guestbook saves in your browser and chat uses rule-based replies; both go live on Netlify. Settings come from `netlify.toml`. Optional environment variables:

| Variable | Purpose |
| --- | --- |
| `ANTHROPIC_API_KEY` | Enables AI replies in Ask Lumi |
| `LUMI_MODEL` | Model for Ask Lumi (defaults to `claude-opus-5-5`) |
| `LUMI_DAILY_CHAT_CAP` | Site-wide daily AI reply cap (default `400`) |

### Refresh the screenshots

```bash
npm i -D playwright
node scripts/capture-screenshots.mjs                          # shoots the live site
BASE_URL=http://localhost:5173 node scripts/capture-screenshots.mjs   # or a local build
```

This writes desktop (1440×900), tablet (768×1024) and phone (390×844) shots into `docs/screenshots/{desktop,tablet,mobile}/`.
