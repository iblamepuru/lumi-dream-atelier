### The 5-point character sheet

1. **Name:** Lumi
2. **What they are:** A tiny moon moth with soft lavender wings, amber eyes and a knitted rose scarf. Quietly brave, curious, gentle, and a little forgetful. Hums lullabies off-key while sewing and collects lost buttons in a thimble.
3. **What they do:** Junior Dream Repairer at Workshop No. 07: mends broken dream crystals with moonlight thread, builds lanterns to shelter them, and flies them home before sunrise.
4. **Their story:** Lumi once woke a fallen star (Polara) that had forgotten how to shine. Lumi now lives in a cosy workshop inside an abandoned brass observatory above the clouds, and dreams of a lantern glowing in every sleeping window of the world.
5. **Tagline:** "Even the smallest light can rescue a dream."

## Built the way the organizers suggested

| Builder tip | How LUMI does it |
|---|---|
| **Pick one core idea and make it feel alive** | One idea, *a moth who mends dreams*, runs through every page; Lumi watches your cursor, changes mood, speaks in a bubble and chats back |
| **Start with Tier 1** | All of Tier 1 first, then all five Tier 2 interactions, then Tier 3 |
| **Test on your phone early** | Every page checked at phone and tablet sizes (screenshots above) |
| **Make the Easter egg delightful** | A sleeping character you can wake (Lumi dozes after 20s of stillness), a secret lullaby in the music box, and five hidden stars that unlock a constellation and a golden crown |
| **Tell the story through motion, not text walls** | Scroll-driven chapters with a travelling light; every section stays under 150 words |
| **Keep the mute button visible** | Sound starts muted; the switch lives in the header on every screen size |

## Tech

React 19 · TypeScript · Vite · Tailwind CSS · Three.js · Web Audio API · HTML5 Canvas · Netlify Functions + Netlify Blobs · Anthropic SDK (Claude).

A static boot screen with inlined CSS paints before the app loads; below-the-fold sections and Three.js load on demand; idle animation loops pause.

**Built to be shared safely**

- **Guestbook:** rate limits stored in Netlify Blobs (3 wishes per visitor per 10 minutes, 60 a day site-wide), a hidden honeypot field and a minimum fill-in time against bots, and gentle moderation that turns away links, emails, phone numbers and rude words with a friendly message. The visitor odometer counts each visitor at most once a day. Visitor IPs are only ever stored as salted hashes.
- **Ask Lumi:** durable per-visitor limits (15 replies per 10 minutes) and a site-wide daily cap (`LUMI_DAILY_CHAT_CAP`, default 400) protect the API budget. The chat says plainly whether Lumi is answering with AI or from the storybook, and falls back to storybook replies whenever AI is unavailable.

**For judges:** a "Start Lumi's journey" checklist on the home page walks the best two minutes (wake the star → repair the crystal → make a lantern → deliver the dream → find a star), and a small *Build notes for judges* link in the footer opens a one-page map of every requirement (`/build-notes`).

```
src/
  components/   hero, character sheet, story, workshop, guestbook, chat, chaos mode, webring…
  projects/     Dream Repair Lab, Lantern Studio, Delivery Navigator
  playroom/     Lullaby Lab, Catch the Falling Dreams
  friends/      Dream Friend Maker
  context/      shared state + localStorage memory
  router.ts     tiny History-API router (no dependencies)
netlify/functions/
  guestbook.mts   /api/guestbook (wishes + visit counter in Netlify Blobs)
  lumi-chat.mts   /api/lumi-chat (Claude, in character, rate limited)
```

### Run it locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm test         # Playwright end-to-end tests (desktop + phone)
npm run lighthouse   # mobile Lighthouse audit, saved to docs/lighthouse/
```

**Tests** (`tests/lumi.spec.ts`, run against a production build with installed Chrome, on desktop and a phone profile): every page renders with no console errors, the 404 page, header navigation and back button, the mute switch remembering its setting, solving the crystal puzzle (and the journey checklist noticing), the guestbook falling back to browser storage, Ask Lumi answering with storybook replies when AI is unavailable, the storybook turning pages by keyboard, the nightlight finding a dream friend with only the arrow keys, and the scroll-synced delivery flight reaching every stop.

Locally the guestbook saves in your browser and the chat uses rule-based replies; both go live on Netlify. Netlify settings come from `netlify.toml`; optional environment variables are `ANTHROPIC_API_KEY` (AI chat) and `LUMI_MODEL` (defaults to `claude-opus-5-5`).
